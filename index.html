Help & Backup Guide

Simple steps your staff can follow to keep data safe and recover it if needed.

Daily / Weekly Backup

The system stores everything (drugs, sales, petty cash, payroll, users) in this computer's browser. To protect against hardware failure, export a backup file regularly and keep it on a safe drive.

  1. Go to the Reports or Admin section.
  2. Click Export Data.
  3. Save the file (for example: pharmastore-backup-2025-12-09.json) to: a USB drive, external hard disk, or secure cloud folder.
  4. Label the drive/folder clearly (e.g. PharmaStore Backups).

Restore From Backup

If you move to a new computer or the data on this browser is cleared, you can restore from the exported file.

  1. Open PharmaStore in the browser.
  2. Log in as an admin.
  3. Go to the Reports or Admin section.
  4. Click Import Data.
  5. Select the most recent backup JSON file.
  6. Confirm the prompt to replace current data with the backup.

After import, verify that drugs, sales history, petty cash, employees and users look correct.

Tips & Best Practices

  • Keep at least one backup off-site (not on the same PC).
  • Do a test restore on a spare machine before relying on backups for the first time.
  • Only trusted staff should have access to backup files and the admin login.
