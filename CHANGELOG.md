## Changelog

### 2025-12-10

- Initial cleanup of legacy online/Firebase auth code to keep the app purely offline.
- Introduced modern UI shell with sidebar navigation, dashboard, and themed components.
- Added offline-friendly fonts/icons and basic print styles.
- Implemented multi-item sales, tax/discount controls, and improved receipt printing.
- Added petty cash, payroll, audit trail, and reports sections wired to existing logic.
- Introduced end-of-day (EOD) summary with optional backup export.
- Added default over-the-counter drugs for new installations.
- Added employee gross/allowance/deduction fields with automatic net salary calculation.
- Implemented basic analytics (7-day sales trend, top selling drugs).
- Added report filters, margin/fast/slow-moving drugs, and top customers.
- Improved security with an admin PIN for destructive actions and richer audit logging.
